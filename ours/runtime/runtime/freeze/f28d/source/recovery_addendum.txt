If the gripper is closed (width < 0.060m) and in contact with or near a supported non-target object (e.g., bowl rim), request 'release_supported_in_place' to open the fingers in place. This prevents dragging the object. Do not request this if the object is the target to be grasped or if the hand is empty and clear. 

If the gripper is open (width > 0.065m) and the hand is near a supported object after a release, request 'clear_supported_object' to withdraw the hand. This is only valid if a supported release was just executed. Do not use this to replace an initial release. 

If a grasp has stalled and the gripper is almost fully closed (width < 0.002m) but empty, with the target visible away from the hand, request 'open_empty_gripper' to retry. Do not use this if the width is not below 0.002m or if the target is not clearly visible and separate. 

If a placement has stalled and the hand is empty, with the object dropped/released outside the destination but supported elsewhere, request 'replan_current_task'. Do not continue the placement. If the object is still held, do not request replan; instead, use 'observe_above' if overhead clearance exists and the target is occluded, or 'observe_only' if unclear. 

If the context indicates a missing target reference or stationary observation, request 'observe_only' or 'observe_above' as appropriate. Do not request 'none' if the controller cannot bind a coordinate.

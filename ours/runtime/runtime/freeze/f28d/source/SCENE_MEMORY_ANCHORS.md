# Scene memory：固定场景锚点

更新：2026-10-26。此修改保留 π0.5 权重、subgoal 文本格式及 V3-R 的归位阶段绘点规则。

## 位置来源与保存规则

| 类型 | 点 | 初始化 | 后续读取 | 失效条件 |
|---|---|---|---|---|
| 炉灶、柜顶、酒架、桌前放置区域 | K3 | 优先 episode 初始图像；缺失时等待首次可靠检测 | 冻结首次可信位置，不受遮挡或后续检测漂移影响 | 相机变换改变、新 episode |
| 炉灶开关 | K1 | 同上 | 同上 | 同上 |
| 顶层抽屉内部 | K3 | 首次当前画面可靠检测，且抽屉已打开、连续5次观测停稳 | 保留这一开度下的位置 | 抽屉移动、关闭、状态证据缺失、相机变化 |
| 碗等可移动物体 | 当前 K1/K3 | 连续5帧静止、受支撑且无机器人接触，双置信度>=0.5时建立阶段缓存 | 当前有效点优先；失检时使用该静止阶段内置信度最高的历史点 | 相对阶段起点平移>5mm或旋转>5°、双指抓持、失去支撑、状态缺失、相机变化 |
| 归位/接管记忆 | 历史 K2 | episode 初始化/指令接管 | 原逻辑不变 | 原逻辑不变 |
| 动态抽屉把手 | K1 | 当前检测 | 不纳入固定锚点 | 原逻辑不变 |

炉灶开关 K1 代表固定操作位置；若未来标签定义为随旋钮转动的表面点，不能继续按固定锚点处理。固定场景锚点假设设施和相机不移动；真机移动相机或家具时需要主动失效/重建，不能盲目复用。

抽屉关闭时可能看不到内部。不能要求初始帧必须取得内部点，也不能缓存关闭位置的点用于打开后的抽屉。本版仅对已有标签实体 top_drawer_interior 实现此处理，不凭空补其他抽屉内部实例。

## 置信度与坐标

- 建立长期锚点：检测置信度与关键点置信度均 >= 0.5。使用环境变量 `HYBRID_ANCHOR_CONF` 调整（范围0.1至1）。0.5是工程默认值，未证明是最优阈值，高置信度也不等于坐标准确。
- 普通当前点仍保持双阈值 >= 0.1。达到0.1但低于0.5的点可以当帧使用，但不会成为长期锚点。
- 坐标仍来自 YOLO，使用现有 MAIN256 -> MAIN224 转换及最终取整；不读取仿真投影坐标补点。
- 初始帧没有可信点时，不写入(0,0)，后续首次可信检测可建立锚点。
- 当前锚点取值优先级：有效冻结锚点 -> 当前检测 -> 原 M1 静态缓存 -> 缺失。

## 日志与接口

`scene_memory.py` 新增 `anchor_acquire`、`anchor_invalidate` 事件。位置绑定记录 `resolution`（fresh/cached）、`source_frame`、`source_time_source`、`age_steps`、`cache_kind`（episode_anchor/stage_anchor等）。历史点仍可服务于“当前目标位置”引用，但日志明确标记来源，不伪装为本帧检测。

`points.py` 在 episode_start 观测后初始化场景锚点，规划可用性查询和最终 prompt 绑定使用同一解析器。每个新 episode 创建独立 Points/SceneMemory，不跨 episode 复用。

## 当前实验边界

抽屉已打开及停稳、可移动物体缓存有效性仍由现有仿真状态模块提供。故仍属于 Agent 规划 + Oracle 阶段/状态判断 + YOLO 位置；不能称为完全非 Oracle。固定设施点本身不需要每步获取真实位姿来保留。

## 2026-10-26：阶段性静止物体缓存

“当前引用”指当前仍然有效的位置，不要求必须来自当前帧。仅可复用当前时刻之前的观测，绝不读取未来帧。

建立缓存与延用缓存分开判断：

- 建立：最近5帧有支撑、无机器人接触，相对窗口末帧平移<=2mm、旋转<=2°，并且YOLO检测/关键点置信度均>=0.5。
- 选取：同一静止阶段内，保留 `min(det_confidence,keypoint_confidence)` 最高的点。低置信度新结果不覆盖高置信度缓存；当前可用点仍按原0.1门槛供当帧使用。
- 延用：当前仍有支撑、没有双指抓持，且相对阶段起点平移<=5mm、旋转<=5°。轻触、短时抖动、YOLO失检本身不再清空缓存。
- 失效：超过上述位姿容差、被抓持、失去支撑、状态证据缺失或相机变化。新episode仍隔离。
- 防累计漂移：选取更高质量的新像素点时，不移动该静止阶段的位姿起点。每次运动都只差一点，也不能无限沿用旧缓存。
- 四元数按实际夹角比较，q与-q视为同一个旋转。

这些是缓存有效性工程门槛，不是修改v2.5任务评分阈值；尚未证明是最优参数。支撑、抓持、位姿差仍来自当前混合实验的仿真状态，像素坐标始终来自YOLO。真机需要另外替换状态证据来源。

可配置变量：`HYBRID_OBJECT_STATIC_WINDOW_M=0.002`、`HYBRID_OBJECT_STATIC_WINDOW_DEG=2`、`HYBRID_OBJECT_CACHE_TRANSLATION_M=0.005`、`HYBRID_OBJECT_CACHE_ROTATION_DEG=5`；长期点双置信度沿用 `HYBRID_ANCHOR_CONF=0.5`。

日志新增 `configuration`、`retain_best`、`object_cache_invalidity`，绑定记录来源帧、置信度和cached状态；新闭环结果中记录 `scene_memory_configuration`。

验证目录：`/mnt/disk_4/geyi/scene_memory_stationary_objects_20261026/`。针对M2炉灶碗案例的原动作/原YOLO输出因果重放：142步碗K3失检时，成功复用第12步高置信度点，完成实际prompt绑定。这仅验证缺点修复，不是新闭环任务成功率。历史M1/M2结果不回填。

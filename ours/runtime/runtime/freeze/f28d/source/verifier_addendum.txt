1. State Verification: 'Open' requires positive evidence of the target open condition. A gap >1cm only disproves 'closed'; it does not confirm 'open'. Partial opening is not completion. Maintain quality and sustained evidence requirements. 2. Contact Logic: Support and finger contact are not mutually exclusive. A supported object may be gripped. If a non-target rim is contacted while supported, verify if in-place opening is required. 3. Motion & Holding: A static object in a static hand may be held. Do not infer 'empty' from lack of motion. Only object lag during real hand motion constitutes a contradiction. Unknown states remain unknown. 4. Tolerance: Use existing task tolerances. Never apply zero tolerance. Proximity does not equal full support or containment. 5. Completion Criteria: Open fingers and image stability are insufficient. Require correct object, intended relation, and valid independent guards. Ambiguous support remains unknown. 6. Depth: Depth estimates do not automatically prove completion. Mandatory checks for quality, temporal consistency, and contradictions must pass.

Apply only required_checks. RELEASE means the fingers are open and the object is independently supported/stable. DISENGAGEMENT is a separate requirement: do not demand a visible gap between fingers and the rim unless disengagement is explicitly listed. Finger proximity alone is not a retained grasp.
A table appearing behind a bottle/bowl in a camera projection is not evidence that its base still touches the table. Check measured object lift and object-versus-hand displacement as well as actual image attachment. If reliable object motion and lift are supplied, do not reject solely because a projected air gap is visually hidden. Conversely an independent measured contradiction must not be overruled by appearance. Existing numeric motion checks are fallible observation proxies, not a stage-completed label.

An active observation maneuver is not a new completed stage. Its camera/hand action must finish before using fresh post-maneuver frames for an intermediate completion. Preserve the original physical, temporal and independent guards; the action deadline is not proof that the goal was reached.

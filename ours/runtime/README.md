本目录冻结的是可审查的共同运行代码、模型身份、提示词和配置。已通过本地离线回归；尚未进行这个合并版本的真实音频、真实模型及机器人动作联合预检。**代码冻结与在线验收分开记录。主 8787/8801 未替换。** 不继承或拼接历史分支成功率。

## 唯一运行链路

```text
原始音频 → Qwen 实时语音 → R7 任务生命周期／R8 语音交互
    → 所有π0.5任务：完整 C3r Agent 与恢复 → 同一 π0.5
仿真观测 → YOLO＋M1 场景记忆 → 阶段验证／有界恢复
独立评分与当前完成校验 → 当前任务回执 → 语音播报
```

F28d 是四角色的研究来源；本次具体执行实现为 **C3r recovery 完整配置**，不是 F28d RawHistory、C3r core 消融配置或旧 SmolVLA 执行器。措辞、规划、视觉验证、恢复四个角色使用同一 `Qwen3.8-27B-FP8` 服务，按需调用，不代表每步串行调用四次。用户原话到 Agent 生成 subgoal 的职责保留；脚本负责验证、选点绑定和执行所有权。

## r5候选：公开状态不含仿真清单时，仍可触发仅音频复核

r4预检T2 OV/G03中，primary把bowl听成ball，模型候选仍正确写bowl，但本地安全守卫拒绝。真实日志无复听；源码确认needsAudioRelisten在scene_inventory=None时直接false。r5只用公开支持物体词表触发只读复听，不向ASR发送词表、图像、任务答案或仿真状态。优先等待同输入独立ASR最多750ms，必要时原有8秒有界纯音频复听；原用户转写保留，不直接替换ball。独立声音证据还必须通过原动作/否定/对象角色/任务身份校验。额外增加词形编辑距离上限，拒绝apple→bowl这类无关名词替换。

新增实际LiveSession方法测试：无scene_inventory仍产出同输入、无reference/scene的声音证据；输入版本变化立即作废；动作/抽屉层/否定与无关物体变化被拒绝。候选尚未真实音频复测，不称已解决该例。

## r6：切换时保持episode策略请求编号连续

原统一网关activate每个新任务重置policy_calls_attempted=0，但模型CID保持episode，导致真实服务Refuse duplicate first call并返回500。r6去掉该重置，沿用已有实际成功请求后递增的R7序列；暂停/续接和新任务共用episode顺序，不重放POST、不改随机种子/模型权重。同时记录真实策略输入、响应哈希，配合既有action_applied供独立评分核对身份链。旧失败不追写这些运行期事件。

## r7候选：分开受理回执与实际执行开始回执

只有当前任务真实policy_action_steps>0且仍running才生成一次短的“机械臂已开始执行当前任务”。不同于指令受理和任务完成；TTS生成后重新核对episode、任务、意图版本、任务版本和运行状态，再转发音频。暂停/恢复不重复开始播报，用户发言/问答优先，旧版本/已完成任务不得迟到播报。原音频、触发、评分时限不改，π0.5权重和动作输入不改。此举修复C3r准备期间受理播报先于第一动作结束、导致无法验证真实执行中插话的接入问题；尚待实际音频验证。
